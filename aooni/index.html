遊び方

町はずれの洋館に入ったひろしたち。玄関の扉は開かなくなり、仲間ともはぐれてしまった。屋敷を調べて謎を解き、先へ進もう。（原作 ver6.23 の本館を、マップどおりの広さで3Dにしています）

  • PC：クリックで視点固定 / WASD 移動 / Shift 走る / マウス 視点 / E・クリック 調べる・扉・隠れる / F・右クリック ライター / Esc 一時停止
  • スマホ：左側ドラッグで移動、右側ドラッグで視点、手のボタンで調べる、走るボタンで走る、炎のボタンでライター。物を直接タップしても調べられます。
  • 屋敷には青い化け物がいる。見つかったら全力で逃げろ。扉を抜けても追ってくる。
  • 部屋を移れば、追ってくるまでに少し時間がかせげる。しばらく見つからずにいれば、あきらめていなくなる。
  • クローゼットに隠れればやり過ごせる。ただし、同じ部屋にいるときに隠れると見つかってしまう。
  • アイテムを拾うたびに自動で記録されます。つかまっても「つづきから」で再開できます。
