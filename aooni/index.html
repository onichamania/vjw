遊び方

町はずれの洋館に入ったひろしたち。玄関の扉は開かなくなり、仲間ともはぐれてしまった。屋敷を調べて謎を解き、脱出を目指そう。（原作 ver6.23 の本館・地下・第１別館・回廊・第２別館を、マップどおりの間取りで3Dにしています）

  • PC：クリックで視点固定 / WASD 移動 / Shift 走る / マウス 視点 / E・クリック 調べる・扉・隠れる / F・右クリック ライター / Esc 一時停止
  • スマホ：左側ドラッグで移動、右側ドラッグで視点、手のボタンで調べる、走るボタンで走る、炎のボタンでライター。物を直接タップしても調べられます。
  • 廊下の先や階段の先が真っ黒になっているところは、原作の画面の切れ目。そのまま黒の中へ進めば、次の場所に出られる。
  • 屋敷には青い化け物がいる。見つかったら全力で逃げろ。扉を抜けても追ってくる。
  • 部屋を移れば、追ってくるまでに少し時間がかせげる。しばらく見つからずにいれば、あきらめていなくなる。
  • クローゼットに隠れればやり過ごせる。ただし、同じ部屋にいるときに隠れると見つかってしまう。
  • イスは「持ち上げる」で運べて、置いた場所で「イスに乗る」と高い所に手が届く。像などの重い物は押して運ぶ。
  • アイテム欄か一時停止の「セーブ」で、３つのファイルに記録できる（追われている間はできない）。アイテムを拾ったときなどにも自動で記録される。つかまっても「つづきから」で再開できる。
