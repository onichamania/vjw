遊び方

ホテルのドアを進み、ドア100の電気室からエレベーターで脱出しよう。部屋は毎回ランダムに生成されます。

  • PC：クリックで視点固定 / WASD 移動 / マウス 視点 / E・クリック 調べる / 1〜6 アイテム / C しゃがむ / Esc 一時停止
  • スマホ：左側ドラッグで移動、右側ドラッグで視点、✋ で調べる・隠れる。物を直接タップしても調べられます。
  • 照明がちらついたら Rush / Ambush。クローゼットかベッドの下へ。
  • 暗い部屋で「プスッ」→ Screech。すぐに振り向いて見つめる。
  • 紫の光 → Eyes。見つめるとダメージ。
  • 壁に目が増えたら Seek の追跡が近い。明かりの方へ走れ。
  • ドア50の図書館とドア100では Figure。しゃがんで静かに。
