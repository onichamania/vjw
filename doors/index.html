遊び方

ホテルのドアを進み、ドア100の電気室からエレベーターで脱出しよう。部屋は毎回ランダムに生成されます。

  • PC：クリックで視点固定 / WASD 移動 / マウス 視点 / E・クリック 調べる / 1〜6 アイテム / G アイテムを置く / C しゃがむ / Esc 一時停止
  • スマホ：左側ドラッグで移動、右側ドラッグで視点、手のボタンで調べる・隠れる、人型のボタンでしゃがむ。物を直接タップしても調べられます。アイテムは長押しで置けます。
  • 照明がちらついたら Rush / Ambush。クローゼットかベッドの下へ。
  • 暗い部屋で「プスッ」と鳴り、画面のふちに黒いもじゃもじゃが出たら Screech。すぐに振り向いて見つめる。
  • ドアの向こうでざわざわと声がして紫の光 → Eyes。最初の2秒ほどは平気だが、見つめ続けるとダメージ。
  • 壁に目が増えたら Seek の追跡が近い。明かりの方へ走れ。
  • ドア50の図書館とドア100では Figure。しゃがんで静かに。
  • オンライン：claude.ai で開いているとき、4人まで同じホテルを協力して進めます。ドア・引き出し・アイテム・レバーはみんなで共有。死んでしまったら仲間を観戦できます。
