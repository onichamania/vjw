# Hello Neighbor Alpha 1 — ファンメイド再現版（Godot 4）

2016年10月26日に公開された **Hello Neighbor Alpha 1**（ビルド3）を、Godot 4 で再現した非公式のファンメイド作品です。
**tinyBuild / Dynamic Pixels とは無関係**です。モデル・テクスチャ・音楽・効果音は、すべてこのプロジェクトのためにコードで作ったオリジナルです（元ゲームのアセットは一切使っていません）。

## 遊び方

1. [Godot 4.4 以降](https://godotengine.org/download)（標準版。.NET 版でなくてよい）をインストールする
2. Godot を起動して「インポート」からこのフォルダの `project.godot` を選ぶ
3. **F5**（再生ボタン）で開始

初回はアセットのインポートで数秒かかります。起動時にお隣さんの移動用ナビゲーションを焼き込むので、タイトル画面が出てから1〜2秒待ってから始めてください。

### 操作

| キー | 動作 |
|---|---|
| WASD / 矢印 | 移動 |
| マウス | 視点 |
| Shift | ダッシュ（足音が大きく、お隣さんや監視カメラに聞こえる） |
| Ctrl / C | しゃがむ（足音を消す） |
| Space | ジャンプ |
| E / 左クリック | 拾う・使う・ドア・隠れる（タンス / ベッドの下） |
| 右クリック長押し → 離す | 投げる（強く投げると窓ガラスが割れる） |
| Q | 捨てる |
| 1〜4 / ホイール | 持ち物の切り替え（4枠） |
| 左クリック（持っている物による） | おもちゃのライフルを撃つ / 懐中電灯 / 双眼鏡でのぞく |
| H | ヒント表示の ON/OFF |
| Esc | ポーズ（設定・操作方法） |

**目的：** お隣さんの家の地下室に入ること。地下室のドアはリビングの階段の下にあり、板が打ち付けられ銅の錠がかかっています。

## Alpha 1 の資料に基づいて再現した内容

### 家（Mr. Peterson の家）
- 青く塗られた板張りの外壁、赤レンガの基礎、白い柵、ポーチと裏口、ガレージ前の車
- 6階建て（入れるのは1〜2階のみ）。3階の高さを **赤い列車** が線路でぐるっと周回し、ランダムに走ったり止まったりする
- **1階**：リビング（青い「耳」柄の壁紙・黒い天井・オレンジ茶の床、三連窓、階段、階段下の地下室ドア）、キッチン（青とピンクの花柄、床にバナナの皮）、ダイニング（白い花柄・タイル）、墓の部屋（ピンクの花柄、床の真ん中が墓穴、3つの出入口のうち2つが家具でふさがれている）、寝室（水色ストライプ、ベッドの下にバール）、バスルーム、ボイラー室（裏口から入る・大きなボイラーとバルブ）、ガレージ（レンガ壁、ハンマー・芝刈り機・工具箱・じょうろ・双眼鏡・トラバサミ、シャッターのスイッチ）、廊下の **エレベーター**（1〜4のボタン、動くのは1・2階だけ）
- **2階**：階段を上がった先の **水没部屋**（機械仕掛けのサメ「シャーコトロン」が泳ぐ・半分沈んだタンスの上にベル）、廊下、**射撃場**（カウンターの柵・天井の2本のパイプ・たくさんのランプ・銀の錠のゲート）、**物置**（突き当たりがむき出しのレンガ壁）、**子供部屋**（ベビーベッドに銅のハートの鍵、テディベアを抱えたマネキン、積み木、子供の絵、外へ飛び降りられるドア）、**教室**（黒板・教卓・生徒の机、2つ目の入口はイスでふさがれている）、2階リビング、**監視室（CCTV）**、床に穴の開いた2階バスルーム（削岩機）、3階への階段（家具でふさがれている）

### 攻略ルート（Alpha 1 の2通りの解法）
- **ピッキング法**：ボイラーのバルブで水を凍らせる → 氷の上を渡る → 監視室の机のピッキングツール → ガレージのハンマー（またはベッド下のバール）で板をはがし、錠をピッキング
- **銅の鍵法**：水没部屋のベル → 墓の部屋の柱に掛ける → 壁の扉からシャベル → 墓を掘って棺 → 先生のマネキン → 教室に立てると紙飛行機のいたずらが止まる → 数字マグネットで計算問題を解く → おもちゃのライフル → 射撃場（電気が必要）で300点 → 銀の鍵 → ゲート → 物置 → 削岩機でレンガを壊す → 子供部屋のベビーベッドの銅のハートの鍵
- どちらの場合も最後は地下室のドア → 明るい光 → お隣さんがドアを叩き閉める → **棺の中で目覚めて、フタを落とされる** エンディング

### お隣さんの AI（Alpha 1 の特徴）
- 見つかると「攻撃モード」になり、**壁越しでもプレイヤーの位置が分かる**（追跡中に隠れても見つかる）。追跡前なら隠れるのは有効
- プレイヤーの進む先を **予測** して先回りし、**近道**（2階バスルームの穴・子供部屋のドアから飛び降りる）も使う
- 走る速さは **全バージョン中で最も遅い**（歩きより遅い）が、**捕まるたびに速くなる**
- 投げた物の音には寄ってこない（Alpha 2 以降と違う）。窓が割れる音・ダッシュの足音・削岩機などには反応する
- 見失った場所・捕まえた場所に **音に反応する監視カメラ** を置く（電気を切るか監視室のボタンで無効化。電気が切れていれば持ち運べる）
- 普段はテレビを見る・窓の外を見る・ダイニングで座る・ベッドで横になる・床をモップがけ・冷蔵庫・庭の見回りなど
- 自分の家のドアは開けて進むが、**プレイヤーの家のドアは開けられない** → 家に誘い込んでドアを閉めると閉じ込められる
- バナナの皮で転ぶ

### その他
- **イントロ**：車で新居へ → お隣さんが双眼鏡を持って2階へ上がり窓からのぞく → 荷物を運び入れて昼寝 → ベッドで目覚めてスタート
- **悪夢のカーニバル（チュートリアル）**：2回捕まる（または2回眠る）と発生。顔を袋で覆ったお隣さんが来るので、タンスかベッドの下に隠れる。彼は反対側の隠れ場所を調べて去っていく
- シャーコトロンに捕まると家の外に放り出される
- 捕まると自分の家のベッドで目覚める
- 音楽：タイトルの不気味なオルゴール・ワルツ、3種類の追跡曲（Alpha 1 にも3曲あった）、カーニバルの手回しオルガン、イントロ、エンディング — **すべて新規に作曲したオリジナル**（元曲の旋律は使っていません）
- 日本語 UI（Noto Sans JP、SIL OFL）

> 部屋の正確な間取り・計算問題の数字などは資料（Wiki の部屋説明・攻略手順）から推定した再構成です。

## 画質設定

設定 →「画質」で 標準 / 高（SSAO・グロー）/ 最高（SDFGI）を切り替えられます。Vulkan が使えない環境では自動的に OpenGL（Compatibility）に切り替わります。

## 開発者向け

```
# 自動テスト（ナビメッシュ到達性・両攻略ルート・AI・悪夢・エンディング）
godot --headless --path . --fixed-fps 60 -- --autotest

# スクリーンショット巡回（画面が必要。Linux なら xvfb-run で可）
godot --path . -- --shots --shotdir=/tmp/shots
godot --path . -- --introshots --shotdir=/tmp/shots

# 音楽・効果音の再生成（numpy, scipy, ffmpeg が必要）
python3 tools/gen_audio.py

# フォントのサブセット作成（Noto Sans JP Bold を Google Fonts から取得して指定）
python3 tools/subset_font.py NotoSansJP-Bold.ttf
```

### 構成

```
scenes/main.tscn              エントリーシーン
scripts/main.gd               全体の進行（環境・ナビ焼き込み・メニュー・各カットシーン）
scripts/game.gd               オートロード：状態・入力・音・騒音/警報システム
scripts/player.gd             一人称プレイヤー（体のモデルなし＝Alpha 1 と同じ）
scripts/neighbor.gd           お隣さん AI
scripts/neighbor_model.gd     お隣さんのモデルと手続き型アニメーション
scripts/world/                家・通り・家具・パズル・カットシーン用の場所・静的バッチ
scripts/objects/              アイテム・ドア・窓・エレベーター・列車・シャーコトロン・監視カメラ等
shaders/                      手続き型の壁紙/板張り/レンガ/床・空・水
audio/                        生成済みの音楽と効果音（OGG）
tools/                        テスト・スクリーンショット・音声/フォント生成スクリプト
```
